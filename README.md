# EmotionWorldGenerator

**EmotionWorldGenerator** — программный комплекс для процедурной генерации трёхмерных виртуальных миров на основе эмоционального состояния пользователя с применением генеративной нейронной сети.

Проект разработан в рамках курсовой работы по дисциплине **«Нейровиртуальные технологии»**.

**Тема:** «Применение генеративных нейросетей для процедурной генерации виртуальных миров на основе эмоционального отклика пользователя».

## О проекте

Основная идея проекта заключается в автоматическом изменении виртуального окружения в зависимости от эмоциональных показателей пользователя.

Система обрабатывает три показателя:

- **Stress** — уровень стресса;
- **Engagement** — уровень вовлечённости;
- **Relaxation** — уровень расслабления.

На основе этих значений определяется одно из четырёх условных эмоциональных состояний: Joy (радость), Sadness (грусть), Stress (стресс) или Calm (спокойствие).

Выбранное состояние передаётся генеративной нейросети CVAE v2, которая формирует параметры виртуального мира. Unity использует их для изменения рельефа, растительности, освещения, цветов и атмосферных эффектов.

## Архитектура системы

Основная последовательность обработки данных:

```text
EMOTIV Launcher / Virtual Brainwear
                 |
                 v
       Cortex API (WebSocket)
                 |
                 v
       EmotionCortexReceiver
                 |
                 v
          EmotionSimulator
                 |
                 v
       EmotionWorldController
                 |
                 v
       NeuralWorldGenerator
                 |
                 v
        CVAE v2 (Barracuda)
                 |
                 v
           WorldGenerator
                 |
                 v
        Виртуальное окружение
```

Предусмотрен также локальный режим симуляции, позволяющий тестировать приложение без внешнего источника данных.

## Генеративная нейросеть CVAE v2

В проекте используется **Conditional Variational Autoencoder (CVAE)** — условный вариационный автоэнкодер.

Модель обучается на синтетических профилях виртуальных миров, соответствующих четырём условным эмоциональным состояниям.

Основные характеристики модели:

- 12 000 обучающих примеров;
- 2 000 проверочных примеров;
- размерность латентного пространства — 8;
- размерность условного вектора — 4;
- количество выходных параметров — 12;
- оптимизатор AdamW.

После обучения декодер экспортируется в ONNX и используется в Unity через Barracuda.

Нейросеть генерирует такие параметры, как высота и детализация рельефа, плотность деревьев и камней, уровень воды, густота тумана, яркость неба и цветовые характеристики.

**CVAE не создаёт готовую 3D-сцену напрямую.** Она формирует управляющие параметры, на основании которых процедурный генератор Unity строит виртуальный мир.

## Генерация виртуального мира

Для построения ландшафта используется шум Перлина и процедурная генерация геометрических сеток Mesh.

Реализованы:

- генерация рельефа с различной высотой и неровностью;
- размещение деревьев, камней и растительности;
- использование импортированных FBX-моделей;
- плавное изменение высоты рельефа и цветов;
- генерация водных поверхностей и декоративных водоёмов;
- погодные и атмосферные эффекты;
- свободное перемещение камеры;
- отображение эмоциональных показателей и графиков их изменения.

Для разных эмоциональных состояний предусмотрены различные визуальные сценарии.

| Эмоция | Характер виртуального мира |
|---|---|
| Joy | Зелёная растительность, яркие цвета и тёплое освещение |
| Sadness | Приглушённые цвета, осенние деревья и дымка |
| Stress | Неровный рельеф, сухие деревья, камни и штормовые эффекты |
| Calm | Плавные холмы, зелёная растительность и мягкое освещение |

## Запуск проекта

1. Установить Unity Hub и Unity Editor версии **2021.3.31f1**.
2. Скачать репозиторий.
3. Открыть папку проекта через Unity Hub.
4. Дождаться импорта ассетов и компиляции C#-скриптов.
5. Открыть основную сцену из папки `Assets/Scenes`.
6. Убедиться, что ONNX-модель назначена компоненту `NeuralWorldGenerator`.
7. Нажать Play.

Для работы в локальном демонстрационном режиме необходимо включить генерацию тестовых значений в `EmotionSimulator`.

Для подключения через EMOTIV Cortex API потребуется запустить EMOTIV Launcher, настроить поддерживаемое виртуальное устройство, зарегистрировать Cortex-приложение и указать параметры авторизации в клиенте Unity. При использовании внешнего источника следует отключить локальную автоматическую симуляцию.

Секреты авторизации Cortex API нельзя публиковать в репозитории.

## Текущий статус

Реализованы генеративная модель CVAE v2, процедурная генерация ландшафта, визуальные эффекты, пользовательский интерфейс и программный клиент EMOTIV Cortex API.

В ходе тестирования подтверждены выполнение ONNX-модели внутри Unity, формирование параметров виртуального окружения, установление WebSocket-соединения с Cortex API и подписка на поток `met`.

Фактическое получение числовых показателей от Virtual Brainwear требует отдельной проверки при отключённой локальной симуляции.

Проект является исследовательским прототипом. Синтетические показатели не являются результатами измерения реальной мозговой активности, а используемые категории эмоций не предназначены для медицинской диагностики.

## Перспективы развития

В дальнейшем планируются полноценная интеграция с физической ЭЭГ-гарнитурой, расширение обучающей выборки, сравнение нейросетевой и традиционной процедурной генерации, повышение производительности и улучшение визуального качества ландшафтов.
